# School Quest Home

School Quest Home is an Expo + React Native learning app for family testing.

## Parent Trust
- Local-first progress on device
- No accounts
- No ads
- Junior and Big Kid modes
- Parent dashboard behind a parent gate

## Features
- Today’s 5 Missions locker flow
- Subject games across reading, math, science, and more
- Junior audio support for early readers

## Run
```bash
npm install
npm start
```

## Build with EAS
```bash
eas build --profile development
eas build --profile preview
eas build --profile production
```
